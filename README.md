# COMP5310 Assignment 1

## Project Overview

This repository contains the code and processed data for COMP5310 Assignment 1.

The assignment evaluates three candidate datasets and prepares the most promising dataset for further analysis. The selected dataset is the NSW Train Occupancy dataset, which is used to investigate patterns associated with passenger crowding and support transport service planning.
