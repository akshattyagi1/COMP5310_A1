## Cleaning evidence

50,250 raw records minus 73 missing outcomes and 250 redundant exact duplicates gives 49,927 records, including 1,994 crowded observations. Text is trimmed, known occupancy spelling variants are mapped, and time-only timestamps are repaired only where a paired timestamp supplies a date. The same-date assumption is limited for overnight services. Outcome fields and actual timestamps/time bands are excluded from features.

## Experiments and evaluation limits

The original benchmark is an 80/20 stratified random split, seed 42. Each candidate has its own training-fitted imputation and encoding/scaling pipeline. The baseline always predicts the majority class. Logistic Regression uses balanced class weights, C=1 and max_iter=1000; Random Forest uses 200 trees and balanced class weights. Both use seed 42.

The random split shares 2,919 trip identifiers. A post-benchmark sensitivity check uses the first fold of StratifiedGroupKFold(n_splits=5, shuffle=True, random_state=42). It has zero trip overlap. This is one grouped holdout, not full cross-validation or chronological validation, and is not represented as an original scope-lock decision.

Grouped crowded recall is 20.00% for Logistic Regression and 3.08% for Random Forest, versus 88.97% and 21.30% on the random split. Do not deploy either model on unseen services based on these results. Logistic Regression is the stronger research candidate under the recall priority, but requires later-data validation and confirmed predictor availability.

## Understanding the confusion matrices

Rows are actual classes and columns are predictions. TP means crowded correctly flagged; FN means crowding missed; FP means a false alarm; TN means non-crowded correctly left unflagged. Recall = TP/(TP+FN); precision = TP/(TP+FP). Accuracy is misleading on its own because about 96% of observations are not crowded.

The random test set has 9,986 observations, including 399 crowded cases. Logistic Regression finds 355, misses 44 and raises 587 false alarms. Random Forest finds 85, misses 314 and raises 11 false alarms. Counts represent observations, not unique services. Figures use predictions directly rather than hardcoded counts.

## Explainability and EDA

Training-only EDA shows imbalance and highest-rate line-direction/station groups (minimum 100 records, not 100 sampled stations). These are descriptive associations, not causes. Permutation importance shuffles each original feature on the held-out set and measures recall decline over five seeded repeats. Correlation can hide feature reliance and shuffling can create implausible combinations; repeat standard deviation is not a performance confidence interval. No test-set explanation is used to tune or select features.

Error-by-line tables show denominators as well as counts. Thresholds 0.25/0.50/0.75 are descriptive test-set comparisons; choosing a new threshold requires separate validation data. Balanced probabilities have not been calibrated.
